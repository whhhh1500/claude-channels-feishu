# /feishu:restart — 重启飞书插件

插件只负责关闭自己；关掉之后你再调用一次插件的工具，Claude Code 发现进程没了，就会用磁盘上最新编译的程序重新拉起插件，并刷新工具列表。按顺序做：

1. 调用飞书 MCP 服务的 `shutdown` 工具（不需要参数）。它会记下飞书是否连着、断开飞书，然后在半秒内退出。记住它的返回，后面要用。
2. 调用一次飞书的 `status` 工具。它能正常返回，就说明新插件已经拉起来了。
   - 调用失败：告诉用户在本会话输入 `/mcp`，重连 `plugin:feishu:feishu`，到此为止。
3. 如果第 1 步的返回说关闭前连着飞书、走 Monitor 监听：用原来的参数重新启动 Monitor 飞书监听（新插件沿用原来的监听地址）。原来那个监听的断开通知不用处理。
4. 用一句话告诉用户插件已经换成新版本。

重启是安全操作，白名单里的用户在飞书里要求也可以执行。
